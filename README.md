# CivicEye AI — Smart Civic Grievance Redressal Platform

This project is organized into two independent sets: **frontend** and **backend**.

---

## Project Structure

- **frontend/**: React 18 + Vite + Tailwind CSS UI application
- **backend/**: Node.js + Express API server with AI vision triage & duplicate clustering

---
 
 
## Quick Start

### Run Frontend:
`ash
npm run dev:frontend
# Or: cd frontend && npm run dev
`

### Run Backend:
`ash
npm run dev:backend
# Or: cd backend && npm run dev
`
